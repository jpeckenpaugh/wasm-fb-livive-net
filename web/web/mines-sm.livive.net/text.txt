mine-sm

A deterministic, no_std 8×8 Minesweeper state machine for reinforcement learning. This page is a browser harness: play the board, inspect the agent-facing observation and action mask, auto-play a guaranteed winning or losing line, and run the conformance checks that validate this JS mirror against the Rust engine.
